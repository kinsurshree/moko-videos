# moko-videos

Public storage for "Moko – छोटा बादल" YouTube Shorts.

- `videos/` – finished episodes (public links are used by Metricool to schedule uploads)
- `episodes/epNN/spec.json` – script of each episode
- `engine/` – the code that turns a script + voice into an episode
- `EPISODE_LOG.md` – what was published and when

Only Moko episode files belong in this repository.
